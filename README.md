# Areal — Rise Hills Building Layout

Прошивки для системы управления подъёмными механизмами и подсветкой архитектурного макета здания **Rise Hills**. Построена на ESP32 (uPesy WROOM), PlatformIO и Arduino framework.

## Архитектура

```
              USB Serial / Bluetooth ("Areal_Master")
                              │
                       ┌──────▼──────┐
                       │   Master    │
                       └──────┬──────┘
                              │  ESP-NOW (WiFi канал 1, 3 попытки + ACK)
      ┌──────────────┬────────┼─────────┬────────────────┐
      ▼              ▼        ▼         ▼                ▼
   m2-1           m2-2       m4      m1-1 / m1-2     LED slaves
 (левый, 2 мот.) (правый,  (центр,   (резерв,        (blue/red/
                  2 мот.)   5 мот.)   1 мот.)         yellow/orange)
```

Один **Master** принимает команды и пересылает их нужным **Slave**-устройствам по ESP-NOW. Каждый Slave хранит настройки (шаги, trim, скорость, ускорение) в NVS, поэтому они сохраняются после отключения питания.

## Структура репозитория

| Папка | Назначение |
|---|---|
| `Areal Msater/` | Master-контроллер — приём команд и маршрутизация по ESP-NOW |
| `Areal motor 2 Slave/` | `m2-1` — левый механизм, 2 синхронных шаговых мотора (TMC2209) |
| `Areal motor 2 Slave copy/` | `m2-2` — правый механизм, аналог `m2-1` |
| `Areal motor 4 Slave/` | `m4` — центральный вертикальный стек из 5 моторов (TB6600 + TMC2209), режимы SIM/SEQ |
| `Areal motor 1 Slave/` | `m1-1`, `m1-2` — одиночный мотор с хомингом (резерв) |
| `Areal slave/` | LED-контроллер: NeoPixel GRBW-лента на 3700 пикселей, эффекты и имитация окон (⚠️ пока не интегрирован) |
| `3d models/` | STL/DXF/DWG модели: лестницы, эскалатор, крепёж, заглушки, лайтбоксы, логотип |
| `Cuts/` | Макеты для лазерной резки (CorelDRAW) — корпуса блоков питания |
| `documentation.txt` | Полная техническая документация: пины, состояния, все команды |
| `commands.txt` | Краткая шпаргалка по командам |

## Сборка и прошивка

Нужен [PlatformIO](https://platformio.org/) (CLI или расширение VS Code). Удобнее всего открыть `Rise Hills Building Layout Slave.code-workspace` — в нём собраны все проекты.

```bash
cd "Areal motor 4 Slave"
pio run -t upload        # собрать и прошить
pio device monitor       # Serial-монитор, 115200 baud
```

Зависимости подтягиваются автоматически из `platformio.ini`:
- моторы — `TMCStepper`, `AccelStepper`
- LED — `Adafruit NeoPixel`, `FastLED`, `NeoPixelBus`

## Команды Master

Отправляются через USB Serial (115200) или Bluetooth `Areal_Master`:

| Команда | Действие |
|---|---|
| `m2-1 up` / `m2-1 down` | левый механизм: подъём / опускание |
| `m2-2 up` / `m2-2 down` | правый механизм: подъём / опускание |
| `m4 up` / `m4 down` | центральный механизм: подъём / опускание |
| `motors up` / `motors down` | все механизмы разом |
| `<цель> stop` | остановка |
| `<цель> mode:sim` / `mode:seq` | одновременное / последовательное движение |

Каждый Slave также принимает собственные команды напрямую по Serial/Bluetooth — `HOME`, `POS`, `SPD:<N>`, `ACC:<N>`, `TRIM1:<N>`, `RESET` и др. Полный список — в [`documentation.txt`](documentation.txt).
